Heimdal
Local collector

Log import and review

Replay a log file locally with Heimdal’s default metric anomaly and authentication rules. The JSON report includes counts and findings with pseudonymous source IDs.

Text and syslog, JSON, JSONL, CSV, TSV, and gzip versions. Up to 5 MiB and 10,000 records.

Recognized percentage aliases with values between 0 and 1 are treated as ratios. Fields named cpu_pct, memory_pct, disk_used_pct, and packet_loss_pct are already percentages.
