# Phase 2: Local Privacy Pipeline & Egress Proof Panel

## Objective and dependencies

Complete the capability under the eight-hour prototype scope. Phase 1 contracts/runtime; can develop alongside phases 3/8 after schema freeze.

Read PROJECT.md, ARCHITECTURE.md, CONTRACTS.md, TEAM_EXECUTION.md, GIT_WORKFLOW.md and VALIDATION.md. Phase numbers are traceability groups, not a serial build queue. See individual MEMBER guides for each person's entire cross-phase workload.

## Files and ownership

backend/collector/sanitizer.py, scrubber.py, egress_panel.py; backend/collector/static/** (M3); frontend receipt view (M2). Ownership exceptions in TEAM_EXECUTION.md apply. M1 alone edits shared contracts, core security and entry-point wiring.

## Tasks

### 1. Construct, do not forward — M1

Parse raw locally, run local summaries, create strict typed metadata with known finite metric fields and enums. Default-drop raw text, stack traces, unknown nested fields and raw IDs. Regex catalog is defense-in-depth, not a guarantee to detect arbitrary secrets.

### 2. Identity and exact body — M1

Use persistent tenant-local HMAC mapping. Serialize approved payload once, save UUID/policy version/body/digest; sender uses those bytes. Retain private mapping locally if required. Never expose credentials as display fields.

### 3. Protect local inspection — M1

Serve loopback-only API requiring session token and exact Host/Origin allow-list; reject wildcard CORS. Bounded raw preview 500 records/15 minutes and purge timer; file permissions; no central raw logging. Label constructed/queued/sent/acknowledged separately.

### 4. Local presentation and adversarial fixtures — M3

Build escaped-text HTML inspector with raw and exact outbound views keyed by UUID. Include synthetic secrets, unknown fields, nested-string attacks and retention cases. Do not implement a separate server or push raw fixtures centrally.

### 5. Central receipt view — M2

Render only actual safe SaaS receipt/body/digest and an instruction to open the separate local page. Compare ID/digest in separate windows. No raw fetch, iframe or bridge.

## Acceptance gate

V03; same UUID/body digest on actual send and receive, negative privacy fixtures, local API protection and retention.

A class import, file presence, fixture output or a mock screen is not completion. Attach observed results/commit SHA in the member status and STATE.md. Do not mark complete while referenced checks are failed or blocked. Changes to contracts require lead review and dependent tests.
