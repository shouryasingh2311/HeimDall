## Tasks

### 1. Single transparent detector — M1

Rolling 30 accepted non-anomalous points per tenant/source/metric; minimum 10-point warm-up. Compute mean/population std BEFORE candidate update. sigma floor: 1 percentage point for CPU/memory, 1ms latency, 0.1 percentage point loss. Flag positive z>3 for two consecutive eligible points; do not learn flagged candidates. Normal points update window. Independent static severe-health alerts need not wait for warm-up. Scope detector to CPU/memory/latency/loss; no seasonal/cron claims.

### 2. Local security — M1

Count failures by local source IP within 10s; >=5 emits risk=min(100,18*count), count/window and attacker pseudonym. Deduplicate raw input IDs locally to avoid replay inflation. Do not forward usernames/passwords. Safe summary enters normal sanitizer/outbox.

### 3. Conservative correlation — M1

Tenant boundary mandatory. Only alerts within 60s and configured connected dependency group join an open incident; unrelated group stays separate. Immediate incident creation/update, no waiting 60s to emit alert. Security alerts form separate category unless an explicit configured relation exists. Persist member alert IDs; no duplicate side effects.

### 4. Honest explanation and score — M1

Likely cause uses graph direction plus event chronology, not earliest timestamp as proof. evidence_score = min(100, 30*min(distinct contributing metrics,2) + 20*has_configured_dependency + 20*has_temporal_order). Booleans are 0/1; temporal_order needs >=2 linked signals with nondecreasing event time. Label heuristic evidence score, not calibrated probability. Include raw formula, observed/baseline/z and payload IDs. No PID/IP/causes absent from metadata. Five consecutive normal eligible samples on all affected sources mark recovering/resolved per explicit rule; stale data cannot resolve incident.

### 5. Controls and quality measurement — M3

Test below-static-threshold anomaly, single benign spike, sustained deviation, zero variance, warm-up, source/tenant independence, late replay, related storm and simultaneous unrelated control. Report noise reduction as 1-incidents/unique alerts for stated related cohort plus unrelated-control result; no fixed 75/80% success claim.

### 6. Evidence-first UI — M2

Show likely cause, score formula label, contributing IDs/values, baseline chart and recommended investigation. Statistical method is sufficient; no LLM dependency.
