# Phase 8: Unified Operations Dashboard & Judge Verification Suite

## Objective and dependencies

Complete the capability under the eight-hour prototype scope. React scaffold starts after G0; each screen consumes phase APIs as available. Not blocked on completion of phase 7.

Read PROJECT.md, ARCHITECTURE.md, CONTRACTS.md, TEAM_EXECUTION.md, GIT_WORKFLOW.md and VALIDATION.md. Phase numbers are traceability groups, not a serial build queue. See individual MEMBER guides for each person's entire cross-phase workload.

## Files and ownership

## Tasks

### 1. Live operations screen — M2

React/Vite, one typed API wrapper, 2s polling, loading/empty/disconnected states, no overlapping requests. Fleet four-state reasons, collector metadata, event-time trends, UTC history, incidents and measured latency. Plain CSS/SVG; skip decorative complexity.

### 2. Evidence views — M2

Actual receipt/metadata inspector; link/instructions for separate loopback proof window, never raw data in SaaS. Incident members/baselines/z/heuristic formula/likely cause. Mocks clearly labelled and disabled for acceptance.

### 3. Actions and results — M2

Wire typed proposal/approval/rollback lifecycle and safe scenario outcomes. Tenant credential switch clears cache. No success on click; render pending/failed/blocked truthfully. Capture first-render measurement as phase 4 specifies.

### 4. Release integration — M1

Serve built frontend same origin, verify HTTPS trust, role/tenant scope for all read/action routes, final clock settings and API schema consistency. Review genuine measurement counts.

### 5. Demo and handover — M3

Write actual install/start/run commands after code exists, expected evidence, known limitations, PDF checkpoint story and separate local/SaaS window procedure. Rehearse clean start and spontaneous scenario order.

### 6. Acceptance and freeze — All

Run V00-V13; build must fail the gate on error. At 7h freeze features, fix only release blockers. Document blocked organizer input/region deployment honestly; do not convert unknown into passed.
