## Tasks

### 1. Organizer-first input — M3

Obtain real format/example; adapt into RawEvent, preserve identity/time and test an actual sample. If absent, mark V00 blocked, use seeded fallback visibly and disclose gap. Do not call guessed format organizer-compatible.

### 2. Deterministic demo source — M3

Two-second ticks for four related roles plus unrelated control; two tenant configs. Include all contracted metrics and explicit source dependencies. Reproducible seed/run ID; warm-up before anomaly scenarios. No raw secrets in committed real data.

### 3. Real input/transport injection — M1 and M3

M3 handlers supply secret records, continued generation during disconnect, auth bursts, latency/loss/service impact, sustained baseline deviation, related/unrelated storm, delivery duplicates/reordering and remediation input. M1 exposes local protected runner and demo-only fault wrapper. Never create incidents or receipts directly.

### 4. Independent observed verifier — M3

Poll actual local outbox, SaaS metadata/alerts and UI receipts with bounded deadlines; return passed/failed/blocked with expected/actual evidence. Scenario 2 outage is 30s; separate offline test stops fresh heartbeats >=65s. Scenario 8 pauses for real operator approval; do not auto-approve.

### 5. Reset and repeat — M3

Reset only source fixture state after pending outbox/commands settle. Keep run IDs and evidence; do not clear dedup DB to make repeat tests pass. Generate new input IDs for new legitimate runs; duplicate tests reuse original body. Run individually and in different orders.

### 6. Scenario results — M2

Display all eight safe results on central UI; local runner owns trigger buttons. No central raw-data bridge; manual independent judge input remains supported.

A class import, file presence, fixture output or a mock screen is not completion. Attach observed results/commit SHA in the member status and STATE.md. Do not mark complete while referenced checks are failed or blocked. Changes to contracts require lead review and dependent tests.
